# GVideo 前端设计系统

## 1. 视觉方向

GVideo 是面向观众与创作者的中文视频社区。默认体验采用浅色、紧凑、内容优先的视觉风格，交互应让成熟视频平台用户感到熟悉，但不复制任何第三方品牌皮肤。

视频封面承担主要色彩，珊瑚红用于关键操作与播放，青绿色用于成功、进度和可信状态。深色模式是受支持的派生主题，新组件必须先完成浅色设计，再通过语义变量适配深色。

## 2. 色彩角色

- 页面背景：`#f6f7f9`
- 内容表面：`#ffffff`
- 主文本：`#18191c`
- 次文本：`#61666d`
- 分隔线：`#e3e5e7`
- 主要操作：`#f05b72`
- 主要操作悬停：`#d94760`
- 成功与健康状态：`#158f84`
- 警告：`#d89b16`
- 焦点环：半透明青绿色

颜色必须表达语义。页面不应被单一色系支配，视频内容应是主要视觉色彩来源。

## 3. 字体与层级

```css
-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB",
"Microsoft YaHei", "Noto Sans SC", sans-serif
```

- 正文至少 `14px`，行高至少 `1.5`
- 功能页标题桌面 `28-32px`，移动端 `24-28px`
- 视频卡片标题 `14-15px`
- 使用字重和间距建立层级
- 不使用斜体、负字距或营销式超大标题

## 4. 组件规范

- 控件圆角最大 `8px`
- 媒体封面桌面圆角 `6px`，窄屏可贴边展示
- 主按钮使用珊瑚红底和白色文字
- 次按钮使用中性表面与边框
- 卡片只用于重复内容、弹窗和真正需要边界的工具
- 页面分区保持无卡片化，不嵌套卡片
- 图标按钮使用 Lucide，并提供 `title` 与可访问名称
- 数值、播放器、工具栏和固定格式控件必须有稳定尺寸

## 5. 页面布局

桌面端使用固定工具顶栏和横向频道导航，不设置常驻左侧栏。发现页在宽屏使用紧凑四列视频网格，播放页使用主播放器列与相关推荐列，创作者和管理页面优先使用便于扫描的行式布局。

播放页顺序固定为：

1. 标题与元数据
2. 播放器
3. 互动操作
4. 作者信息与简介
5. 评论区

字幕创作和管理只存在于 `/me/videos` 投稿管理流程，播放页只选择字幕轨道，不得把字幕管理放到评论区上方或播放页内容流中。

## 6. 层次与阴影

大多数层级由留白和分隔线建立。菜单、弹窗和选中状态可以使用轻量阴影：

```css
rgba(0,0,0,.02) 0 0 0 1px,
rgba(0,0,0,.04) 0 2px 6px,
rgba(0,0,0,.10) 0 4px 8px
```

内容卡片不使用厚重阴影。播放器作为主要媒体表面，可以比普通内容稍有更强层次。

## 7. 交互状态

必须覆盖加载、空状态、错误、成功反馈、禁用、处理中、转码进度、失败重试、键盘焦点和图片加载失败回退。

常用观看操作应保持可见和可预测。搜索、筛选、排序和分页状态优先保存在 URL 中。

## 8. 响应式规则

- `> 1180px`：四列发现网格、双栏播放布局
- `921-1180px`：三列发现网格、较窄推荐栏
- `701-920px`：移动抽屉导航、单栏播放、两列推荐
- `<= 700px`：紧凑顶栏、两列视频网格、贴边播放器
- `<= 430px`：单列视频网格、堆叠管理控件

所有支持视口都不得出现页面级横向滚动，文字不得与按钮、前后内容或固定控件重叠。

## 9. 动效规范

动效只用于反馈和状态变化。封面缩放、按钮反馈、菜单、抽屉、进度和焦点过渡使用 `150-250ms`，只声明目标属性，不使用 `transition: all`。

悬停效果只应用于精细指针设备。所有动画和过渡必须尊重 `prefers-reduced-motion`。

## 10. 禁止项

- 不把字幕管理放到播放页或评论区上方
- 不使用桌面常驻侧边导航
- 不使用彩色竖线、嵌套卡片和装饰性超大标题
- 不用渐变光球、散景或纯氛围素材代替真实内容
- 不让不熟悉的图标控件失去文字说明或 Tooltip
- 不用单一紫色、米色、深蓝或棕橙色系统统治整个页面
- 不允许组件因动态图标、加载文字或数字变化而跳动布局
